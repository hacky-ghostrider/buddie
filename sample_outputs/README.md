# Sample Outputs

Committed examples of evaluation / quality / benchmark artifacts for README
browsing. Runtime outputs from `make demo` go to `data/demo/`
(gitignored) and may differ slightly.

| File | Description |
|------|-------------|
| `evaluation.json` | Structured evaluation report |
| `evaluation.csv` | Tabular export |
| `evaluation.html` | Human-readable evaluation page |
| `quality_report.html` | Quality gate decision page |
| `benchmark.csv` | Suite rollup |
| `langsmith_trace_placeholder.md` | Where to drop a LangSmith screenshot |
